# HI-09 — GPX 내보내기 (P1, 클라이언트 전용)

작성: flutter-ui-designer · 2026-08-31

## 목표

러닝 상세 화면에서 해당 러닝을 GPX 1.1 파일로 내보내 OS 공유 시트로 전달.
위치 이력은 사용자 자산(PRD §6) — 표준 포맷으로 다른 앱/지도 서비스로 이동 가능하게 한다.
서버 렌더링 불필요(TRD §12) — `RunRecord.samples`만으로 클라이언트에서 직렬화.

## 설계 결정

- **외부 패키지 없음.** `xml`은 pubspec.lock에 전이 의존성으로만 존재. GPX는 중첩 3단계,
  요소 10개 미만이라 `StringBuffer` + 수동 이스케이프로 충분. 새 직접 의존성을 추가하지 않았다.
- **인코더/서비스 분리.** `sharing/data/share_service.dart`와 같은 구조 — 인코더는 순수 함수라
  단위 테스트하고, 서비스는 `path_provider` + `share_plus` 플랫폼 채널이라 통합 지점에서만 본다.
- **XML 이스케이프.** `& < > " '` 5종을 룬 단위로 치환. 제목(`title`)이 유일한 사용자 입력 텍스트 노드.
- **시각 포맷.** `DateTime.toIso8601String()`은 `.000`을 붙이고 로컬이면 오프셋을 붙이므로
  직접 조립: `YYYY-MM-DDThh:mm:ssZ` (UTC 고정). 샘플 `timestamp`·`startedAt` 모두 모델 규약상 UTC.
- **좌표 정밀도.** 7자리(`toStringAsFixed(7)`) ≈ 1cm — GPS 원본 손실 없음.
- **심박/케이던스.** Garmin `TrackPointExtension` 네임스페이스(`gpxtpx:hr` / `gpxtpx:cad`).
  값이 없으면 `<extensions>` 블록 자체를 생략. 고도(`<ele>`)도 `altitudeMeters` 있을 때만.
- **좌표 null 샘플(실내 러닝) 처리.** `<trkpt>`에서 조용히 스킵. 좌표 샘플 2개 미만이면
  `hasExportableRoute`가 false → 상세 화면이 오버플로 메뉴를 아예 렌더하지 않는다
  (편집 버튼만 남음). 실내 러닝·GPS 전면 유실 기록에서 죽은 메뉴가 안 뜬다.
- **파일명.** `runnit_YYYYMMDD_HHMM.gpx` (시작 시각 로컬). 캐시 디렉터리(`gpx_exports/`)에 쓴다 —
  공유 후 쓸모없어 OS가 공간 부족 시 정리.
- **결과 처리.** `GpxExportOutcome` — `presented`/`dismissed`/`noRoute`/`failed`.
  공유 카드([ShareOutcome])와 같은 이유로 "게시 성공"을 단언하지 않는다(OS가 알려주지 않음).
  준비 스낵바를 먼저 띄우고 `failed`/`noRoute`일 때만 실패 안내로 덮는다.

## 남은 이슈

- **실기기 공유 시트 검증 보류** — `share_plus` `shareXFiles` + `application/gpx+xml` MIME 타입이
  iOS/Android 대상 앱 목록에 제대로 뜨는지는 실기기 확인 필요(위젯 테스트 범위 밖).
- ~~iPad 팝오버 앵커(`sharePositionOrigin`)는 헤더 액션의 `RenderBox`에서 계산~~ — **초판은 그렇지 않았다.**
  `RunDetailPage.build`의 `context`로 계산해 앵커가 화면 전체 사각형이었다(QA A-6).
  2026-09-01에 오버플로 `PopupMenuButton`에 `GlobalKey`를 달고 `shareOriginOfKey`로 계산하도록 수정.
  자세한 내역은 `_workspace/20260901_ui_hi09-ipad-anchor.md`. 실기기 확인은 여전히 권장.
- **polyline-only 기록은 내보내기 대상이 아니다**(QA A-7). `routePolyline`에는 좌표만 있고
  per-point `timestamp`가 없어 `<trkpt><time>`을 채울 수 없다 — 시간축 없는 GPX는 반쪽짜리라
  제외한다. 그래서 좌표가 `routePolyline`에만 남은 구버전/샘플 유실 기록은 **지도는 그려지지만
  GPX 메뉴는 뜨지 않는다**(`hasExportableRoute`는 `samples`만 본다). 의도된 비대칭.
- GPX에 `<trk><type>`만 넣었고 요약 통계(총 거리·시간)는 담지 않았다. GPX 1.1 표준에 러닝 요약
  전용 요소가 없고 대부분 소비 앱이 트랙에서 재계산하므로 의도적으로 생략.

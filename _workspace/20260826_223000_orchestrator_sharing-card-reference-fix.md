# 공유 카드 규격 수정 — 사용자 레퍼런스 반영 (16:9 → 9:16, 그림자 제거)

**날짜:** 2026-08-26 · **담당:** 오케스트레이터(직접 작업, 에이전트 위임 없음) · **범위:** PRD HI-08/HI-10

## 배경

flutter-ui-designer가 "배경 없고 16:9 페이지" 요청을 가로 밴드로 구현했으나(`_workspace/20260826_213000_ui_sharing-card-overlay-redesign.md`),
사용자가 실제 레퍼런스 이미지(`Slide 16_9 - 3.png`)를 제공했다. 이 파일은 **투명 배경 + 흰색
콘텐츠**로 되어 있어 흰 배경 뷰어에서는 완전히 빈 화면으로 보였다 — 검은 배경에 합성해서야
실제 디자인(세로 9:16, 중앙 정렬 단일 컬럼: 워드마크 → 촬영 시각 → 경로 라인아트 → Distance/
Pace/Time 스택, 그림자 없음)을 확인할 수 있었다.

## 처리

1. `share_card_renderer.dart`/`share_card_surface.dart`/`share_card_sheet.dart`의 16:9 규격을
   9:16(1080×1920)으로 되돌림.
2. `share_card_body.dart` 전면 재작성 — 가로 밴드(머리띠+2열 본문) 레이아웃을 세로 1열 중앙
   정렬 컬럼으로 교체. 기록 카드는 레퍼런스 그대로 영문 라벨(`Distance`/`Pace`/`Time`)과 콜론
   페이스 표기(`5:51 /km`)를 쓰고 헤드라인이 없다. 성취 카드(티어/뱃지/PB) 3종은 레퍼런스에
   없었으므로 같은 시각 언어를 유지하되 헤드라인/부제를 추가했다.
3. 사용자 후속 지시("shadow 빼")로 `shareCardTextShadows`/`shareCardHaloColor`를 전부 제거 —
   텍스트와 경로 선 모두 순수한 흰색으로만 그린다.
4. 실내 러닝(경로 없음) 폴백 아이콘은 그대로 유지 — "달리는 표시가 왜 있냐"는 지적은 실제로는
   0km/GPS 미이동 테스트 러닝이라 경로가 없었던 것이었다. 시뮬레이터 위치를 실제로 이동시켜
   (`xcrun simctl location start`) 재확인한 결과 경로가 있으면 정상적으로 라인아트가 그려진다.
5. `test/sharing/share_card_body_test.dart` 갱신 — 새 라벨/포맷/레이아웃에 맞게 기대값 수정.
6. `docs/TRD.md` §3.9.2를 규격 히스토리 표(9:16→16:9→9:16)로 재작성, v0.8 릴리스 노트 추가.
   `docs/ARCHITECTURE.md`의 16:9 언급도 9:16으로 정정.

## 검증

- `flutter analyze` 0건, `flutter test` 140/140 통과.
- 시뮬레이터(iPhone 17 Pro)에서 실제 GPS 이동을 시뮬레이션한 러닝으로 공유 화면을 직접 확인:
  투명 체커보드 배경, `Runnit` 워드마크(Orbitron), 날짜+시각, 꺾인 경로 라인아트(그림자 없음),
  `Distance`/`Pace`/`Time` 스택 전부 사용자 레퍼런스와 일치.

## 남은 것

- 성취 카드(티어/뱃지/PB) 3종은 사용자 레퍼런스가 없었으므로 오케스트레이터 판단으로
  헤드라인/부제를 유지했다 — 추후 사용자가 이 3종도 레퍼런스를 준다면 재조정 필요.
- PRD §5.2 HI-08 원문은 "9:16 지원"이라 비율 자체는 이번 수정으로 다시 합치됐지만, "배경 없는
  오버레이 스티커"·"그림자 없음"은 PRD 원문에 없던 구현 세부 확장이다. 실사용에 문제가 없다면
  PRD 갱신은 보류.
